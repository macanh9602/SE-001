# Editor UX review checklist

> Mỗi dòng phải được đánh dấu `PASS`, `FAIL`, `N/A` hoặc `PENDING` sau khi thao tác thật.

| Verdict | Dimension / check |
|---|---|
| PENDING | Task completion: hoàn thành workflow authoring chính |
| PENDING | Discoverability: tìm thấy New/Open/Save/Play Test |
| PENDING | Information architecture: field và action nằm đúng nhóm |
| PENDING | Interaction quality: input, drag, undo và focus đúng intent |
| PENDING | Error recovery: sửa malformed/dirty/blocking state an toàn |
| PENDING | Visual hierarchy: canvas và task hiện tại là trọng tâm |
| PENDING | Control sizing and density: click target và mật độ dùng được |
| PENDING | Semantic color: state không phụ thuộc riêng vào màu |
| PENDING | Icon usage: icon có label/tooltip phù hợp |
| PENDING | Frequency-based emphasis: thường dùng luôn thấy, hiếm nằm advanced |
| PENDING | Responsive layout: width khoảng 640px vẫn dùng được |
| PENDING | Accessibility/readability: text, contrast, focus và status đọc được |
| PENDING | GD terminology: không cần hiểu code/schema |
| PENDING | First-use: workflow đầu tiên không cần tài liệu |
| PENDING | Toolbar global actions giữ vị trí giữa các mode |
| PENDING | Inspector dài có scroll riêng |
| PENDING | Blocking issue xuất hiện ở canvas, field, panel, Save/load |
| PENDING | Click issue chọn đúng stable ID và focus đúng field |
| PENDING | Một gesture kéo tạo một undo entry |
| PENDING | Domain reload/reopen giữ document context cần thiết |
