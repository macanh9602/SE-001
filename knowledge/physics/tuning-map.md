# Physics tuning map

| User sees | Likely cause | Tune |
|---|---|---|
| falls like paper | acceleration/damping ratio | gravity, damping |
| impact weak | impact speed/restitution/cues | restitution, impulse, VFX/audio |
| bounces forever | high restitution/low damping | bounciness, damping |
| slides like ice | low friction | material friction |
| rolls forever | low angular damping/resistance | angular damping, rolling resistance |
| stack never settles | solver/contact/COM/sleep | collider, solver, COM, sleep |
