Bowl leveling speed follow-up

GD asked for faster leveling and more grains joining the flow. SandSimulationProfile now exposes bowlLevelingCellsPerStep (default 3, range 1–4) and bowlLevelingExtraPasses (default 1, range 0–3). The first advances a grain farther along a verified free path; the second revisits only the registered Bowl region so grains exposed by earlier moves can flow in the same simulation step. Existing bowlCreepChance is already 1, so raising it cannot recruit more grains. The extra pass uses a preallocated byte stamp and the cached Bowl bounds; no per-step allocation or extra rendering. Worst-case extra memory is one byte per simulation cell. Redmi 9A CPU profiling and a visual Play Test remain pending.
