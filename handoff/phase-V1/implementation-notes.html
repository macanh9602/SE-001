Approach and decisions

  • Used the locked C2C spec. Frontier mode is AUTO; the workspace adapter was unavailable, so the local fallback was used after workspace/branch preflight confirmed SE-001, branch main, dirty worktree.
  • Kept CupProfile.taper = 0 as locked. Grep showed fillLine participates in CupDomain capacity/Required accounting, so fillLine = 0.85 is retained; only the visual FillLine was removed.
  • Kept old MAT_Source, MAT_Cup, and MAT_CupBack as deletion candidates; no destructive cleanup was performed.

Implemented

  • Added JarVisualProfile with measured composition constants, baked silhouettes, Source fill mask, area LUT, and sparkle noise.
  • Added SE001_JarTint, SE001_JarSandFill, and SE001_JarShadow; tint math is shared with the Editor CPU mirror.
  • Generated 14 color materials and wired them through ColorProfile; ids 1–7 remain backward-compatible.
  • Rebuilt authored quad mesh assets and prefabs. Source hierarchy is Pivot/View/{Shadow,SandFill,Body,Mouth}; Cup hierarchy is View/{Shadow,Body,CapTop,CapBottom}.
  • Corrected Source orientation: authored mouth-down art is idle at 180° (mouth up) and transitions to 0° while pouring; BodyOffset and Editor preview now match this pose.
  • Source fill uses one reusable MPB, area-correct LUT, world-down object-space direction, and no per-frame material/mesh allocation. Source shadow offset is kept in world space while the pivot rotates.
  • Cup uses fixed-thickness 9-slice caps and body height stretch. Foreign feedback is applied to cap renderers through one reusable MPB.
  • Aligned CupDomain sink geometry to the authored Cup Body: JarVisualProfile.cupBodyInnerInsetPixels = 7 defines the glass edge, while cupBodyOffsetYPixels = 41 and Inspector-tunable cupSandBottomOffsetPixels = 0 define the sand bottom. Positive offset raises sand; negative offset lowers it. LevelSpawner passes the same profile into CupDomain, so sand stays inside the Body width and does not render below its visual bottom.
  • Added deterministic Editor generator, mask baker, prefab rebuild, cached preview utility, and preview grid generation.
